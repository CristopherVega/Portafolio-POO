# Portafolio POO

Simulador de un reproductor de música en consola, desarrollado en Java con programación orientada a objetos como portafolio del curso en UCENFOTEC.

## Estructura
- `src/`: código fuente del proyecto

# Características
- Simula un reproductor de música que se usa desde la consola
- El reproductor pausa, continua o pasa a la siguiente cancion , en base a las canciones de su playlist 
- Desarrollado aplicando clases, encapsulamiento, herencia y polimorfismo
